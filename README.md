# IPL Analytics Dashboard (Excel)

## Overview

This project is an interactive IPL Analytics Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, KPI Cards, and Slicers.

The dashboard provides insights into IPL matches across multiple seasons, including team performance, player achievements, venue analysis, and toss decision trends.

## Features

- KPI Cards
  - Total Matches
  - Total Seasons
  - Total Venues
  - Player of Match Awards

- Visualizations
  - Matches Played per Season
  - Team Wins Analysis
  - Toss Decision Analysis
  - Top 10 Player of Match Winners
  - Most Used Venues

- Interactive Filtering
  - Pivot Tables
  - Pivot Charts
  - Slicers

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Cards
- Data Analysis
